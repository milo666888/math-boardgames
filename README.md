# 數學桌遊館

「抓鬼特工」（指數）與「畫地取寶」（特殊角廣義三角）兩套數學桌遊的線上版，共 6 種玩法：
抓鬼特工、綠色能源、抽卡PK賽、配對PK賽、急中生智、勝者為王。

- **一個人玩**：進入座位頁後，空位按「＋電腦」補人，並可選電腦強度（簡單／普通／困難）。
- **線上遊戲室**：選好遊戲、人數與每手限時後按「開始遊戲」，座位頁會自動產生 4 位數房號與 QR code；同學打開同一個網址，輸入房號（或掃 QR code），填座號與姓名即可入座。
- **每手限時**：每個遊戲依難度預設每手秒數，開局前可以改或自訂；超時跳過這一手，連續兩手沒出手由電腦代打，按「我回來了」即可接回。

## 技術說明

- 單一靜態網頁（`index.html`），可放在 GitHub Pages 或 Vercel，不需要資料庫。
- 線上遊戲室採 WebRTC 點對點：主持人的裝置負責判定規則與電腦玩家，其他裝置直接連到主持人。配對牽線使用 PeerJS 的公開服務，遊戲資料不經過伺服器保存。
- 主持人的遊戲室畫面要保持開著，遊戲室才會存在。
